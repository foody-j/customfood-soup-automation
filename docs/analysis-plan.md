## 1. 연구 질문 (Research Questions)

| | 질문 | 분석 |
|---|---|---|
| **RQ1 (주)** | 비접촉 센서(카메라 + 열화상)만으로 PT100 기준 조리 상태(미완/완료/과조리)와 **완료 시점**을 판정할 수 있는가? | §6 모델 비교 |
| RQ2 | 객관 라벨(표준 레시피 + PT100 곡선, D-041)과 관능 판정(맛보기)은 얼마나 일치하는가? | §7 라벨 타당성 |
| RQ3 | 같은 조건에서 가열 과정·완료 시점은 얼마나 재현되는가? 조건(출력·추가 물·뚜껑)은 완료 시점에 얼마나 영향을 주는가? | §8 공정 특성 |
| RQ4 (보조) | 센서별 기여(열화상 vs 카메라)와 데이터 양에 따른 성능 변화 | §6 절제·학습 곡선 |

## 2. 가설 (Hypotheses)

- **H1 (주 가설):** 탐침 없는 모델(`noprobe` = 열화상 + 카메라 + 경과 시간 + 조건)의 **완료 알림 시각 절대오차**가 경과 시간·조건만 쓴
  기준선(`trivial`)보다 작다. 세션별 짝지은 비교, Wilcoxon 부호순위 검정(단측), α = 0.05.
- H2 (추정 중심): 관능 완료 시작 − 객관 완료 시작의 평균(편향)과 95% 일치 한계(Bland–Altman). 사전 기준 없이 추정값과 신뢰구간을 보고한다.
- H3: 인덕션 출력 수준이 끓기 시작 시각과 가열 속도에 영향을 준다(출력이 높을수록 빠르다). 뚜껑·추가 물 효과는 탐색적으로 본다.

## 3. 실험 설계

- **단계:** ① 물 가열(장비 특성·PT100 보정, 출력 3수준 × 2회) → ② 국 **기준 조건 반복**(4~5회) → ③ 국 **조건 변화**(나머지).
  목표 국 세션 16~20회(기준 반복 포함). 근거는 일정(8주)과 학습 곡선(§6.5)으로 보고한다.
- **조건 매트릭스:** 출력 3(낮음/중간/높음) × 추가 물 2(0/200 mL) × 뚜껑 2(덮음/엶) = 12조합.
- **무작위화:** 조건 변화 세션은 12조합을 블록 단위로 무작위 순서(고정 시드)로 돌린다. 기준 조건 반복은 사이사이에 끼워
  시간에 따른 표류(장비·계절·숙련도)를 볼 수 있게 한다. 순서표: `research/soup schedule --seed 20261020 --soup 18 --ref 5`.
  (실제로 지킨 순서와 어긋난 세션은 변경 기록에 남긴다.)
- **고정 조건:** 같은 솥·위치·제품(같은 로트 우선)·조명·카메라 위치, 탐침은 가운데 고정 깊이 — 세션마다 조건 키-값으로 기록(Pi params).

## 4. 라벨 정의 (D-041)

- **주 정답(`label`)** = 객관 라벨: 완료 시작 = 표준 레시피 기준(레토르트는 포장지 조리법; 확인 전 잠정 규칙 `boil` = PT100 끓기 시작),
  과조리 시작 = 규칙 `mark`(Pi 과조리 사건). 규칙 파일 `~/soup-data/label_rules.json`을 데이터셋 동결 시 summary에 기록한다.
- **보조 정답(`label_sensory`)** = Pi 관능 사건(완료 시작·완료 끝·과조리). 주 분석이 아니라 §7 타당성 검증과 민감도 분석에 쓴다.
- **경계 완충대:** 각 경계 ±60초는 "경계 제외 F1"에서 빼고(주 F1에는 포함), 학습에는 기본 포함한다.
- **정답 누설 방지:** PT100에서 나온 열(`probe_columns`)은 `trivial`·`thermal`·`camera`·`noprobe` 입력에서 제외한다(코드가 섞이면 멈춘다).

## 5. 세션 제외 기준 (사전 고정)

판정 기록(`review`)의 이유 앞에 코드를 붙인다(예: `E3: 카메라 ② 렌즈 가림`). 논문에는 세션 흐름도(기록 → 무결성 → 판정 → 라벨 → 분석)로 보고한다.

| 코드 | 기준 | 영향 범위 |
|---|---|---|
| E1 | 무결성 실패(Fedora sha256 불일치) | 모든 분석에서 제외 |
| E2 | 기본 4스트림 중 누락이 있거나 저장률 < 95% | 모든 분석에서 제외 |
| E3 | 카메라 초점 흐림·가림(선명도 중앙값 < 5, 자동 경고) | 카메라를 쓰는 트랙(`camera`·`noprobe`·`all`)에서 제외. **김 서림은 제외 사유가 아니다**(실제 조건 — §9 하위군 분석) |
| E4 | PT100 끓기 시작 미검출 또는 탐침 이탈(끓는 구간 온도가 기대 끓는점과 5 ℃ 넘게 다르고 보정으로 설명 안 됨) | 객관 라벨이 필요한 분석에서 제외 |
| E5 | 프로토콜 위반: 과조리 전 종료, 조건 기록 없음, 정해진 제품 아님 | 과조리 관련 분석 또는 조건 분석에서 제외 |
| E6 | 기타(사람 판정) — 이유를 반드시 적고 논문에 개별 보고 | 판정에 적은 범위 |

## 6. 모델 비교 (RQ1·RQ4)

- **트랙:** `trivial`(경과 시간 + 조건) / `thermal` / `camera` / **`noprobe`** / `probe`(참고용 상한 — 정답과 같은 출처). 모델은
  수작업 특징(과거 창 30·120·300초) + HistGradientBoosting(코드 기본 하이퍼파라미터 고정, **시험 세션으로 조정하지 않음**).
- **평가:** 세션 하나씩 빼고 학습(LOSO). 학습 행은 5초 간격.
- **완료 알림 규칙(고정):** P(완료 이상)을 지수 평활(시상수 20초) → 0.5 이상이 30초 이어지는 순간 알림. 과조리 알림도 같은 규칙.
- **주 지표:** 세션별 완료 알림 시각 절대오차(초)의 중앙값. **보조 지표:** macro-F1(전체·경계 제외), 순서 오차(MAE), 조기 경보율(정답보다 60초 넘게
  이른 알림), 놓침률, 과조리 알림 오차.
- **불확실성:** 세션 단위 부트스트랩 95% 신뢰구간(B = 2000, 고정 시드).
- **검정:** H1은 `noprobe` vs `trivial` 세션별 절대오차의 Wilcoxon 부호순위(단측). 보조 비교(`thermal`·`camera` vs `trivial`,
  `noprobe` vs `thermal`·`camera`)는 양측 검정 + Holm 보정.
- **학습 곡선(§6.5):** 학습 세션 수 4·8·12·(16) — 각 크기 3회 무작위 표본, `noprobe`·`trivial`.
- **해석 보조:** 센서 묶음별 순열 중요도(경과 시간·조건·열화상·카메라)를 시험 세션에서 계산해 평균.

## 7. 라벨 타당성 (RQ2)

- 관능 완료 시작 − 객관 완료 시작: 평균(편향), SD, 95% 일치 한계, 편향의 95% CI — Bland–Altman 그림.
- 맛보기 판정 vs 그 시각의 객관 라벨: 일치율, 2차 가중 Cohen's κ(순서형 3단계).
- 판정자 1인 한계를 보고하고, 기준 조건 반복 세션에서 관능 완료 시각의 흔들림(SD)을 판정 일관성 근거로 쓴다.

## 8. 공정 특성 (RQ3)

- 세션별: 끓기 시작 시각, 끓는 구간 온도(PT100 보정 점검), 75 ℃ 1분 유지 시각(참고선), 40→80 ℃ 가열 속도, 끓기 전 1차 가열 모델
  T(t) = T∞ − (T∞ − T₀)·e^(−t/τ)의 τ, 조리값 C₁₀₀, (질량 기록 시) 열량·증발 추정.
- 기준 조건 반복: 평균 ± SD, 변동계수(CV %).
- 조건 효과: 끓기 시작 시각·가열 속도 ~ 출력 + 추가 물 + 뚜껑. 표본이 작아 요인별 Kruskal–Wallis와 출력 수준의 Spearman 상관을
  주 분석으로, 선형 모형(OLS, 유형 II 분산분석)은 보조로 보고한다.

## 10. 계획된 표·그림 (`research/soup paper`가 생성)

- 표: ① 데이터셋 요약 ② 장비·센서 사양 ③ 모델 비교(지표 + 95% CI + 검정) ④ 조건별 가열 특성 ⑤ 라벨 일치.
- 그림: ① 시스템·센서 배치(사진·도식 — 사람이 준비) ② 세션 흐름도 ③ 대표 세션(온도·라벨 구간·사건) ④ 조건별 가열 곡선
  ⑤ Bland–Altman ⑥ 모델 비교(CI) ⑦ 세션별 알림 오차 ⑧ 학습 곡선 ⑨ 혼동 행렬 ⑩ 센서 묶음별 중요도.
- 모든 산출물에 출처 도장(데이터셋 지문·코드 커밋·라벨 규칙·보정값·패키지 버전)을 함께 저장한다.
