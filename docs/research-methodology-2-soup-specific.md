---

## 0. TL;DR — 국/탕은 "색" 대신 이걸로

색이 약한 국물요리에서 **색 없이도 학습되는 시각 신호**로 문헌이 검증한 것:
1. **끓음/거품 동역학** (bubble dynamics) — RGB만으로 강함
2. **국물 탁도/농도** (turbidity, 우러남) — 이미지→연속값 회귀 가능
3. **건더기 무름** — milestone 분류(색 아님)로 잡음

여기에 **온도(A) + 비전(B) 융합**을 gated attention으로, **소량 데이터**는 전이학습+자기지도+약지도로 메움. → 1차의 A+B 상보 전략이 구체 기법 수준으로 확정됨.

## §1. 색 외 완료 신호 (앵글 1) — 핵심 발견

### (a) 끓음/거품 동역학 ✅ [high]
- CNN+객체탐지가 **고속 거품 영상(생성·병합·이탈)으로 열유속(heat flux)을 ~6% 오차**로 예측. 평균 거품 크기∝열유속(선형), 거품 수는 병합되며 지수 감소 → **크기·개수·병합률**이 구체 피처. (Nature SciRep 2021)
- **BubbleID (J.Appl.Phys. 2024)** = 재사용 가능한 파이프라인: **Mask R-CNN 인스턴스 분할 + SORT/OC-SORT 추적**으로 거품 생애주기 정량화. *단, "거품 개별 속성(속도·계면형상)까지 다 뽑는다"는 세부 주장은 검증에서 반박(§반박) → 파이프라인 골격만 참고.*
- **YOLO 쿡탑 시스템**: '뚜껑 없는 냄비 + 물 끓음'을 **이산 시각 클래스로 탐지(recall 0.996), RGB만으로** 화력 제어 트리거. → 국/탕 "끓기 시작" 감지에 직접 이식.
- ⚠️ 거품 논문들은 **가열면 pool-boiling** 실험 → 건더기 있는 탁한 국물 표면엔 재검증 필요(공학적 외삽).

### (b) 국물 탁도/농도(우러남) ✅ [high]
- **Turbidivision (2024)**: **YOLOv8-Classification + 전이학습**으로 이미지를 11탁도 클래스(675장)로 분류 → **top-5 신뢰도에 가중최소제곱 회귀 → 연속 탁도값**. 정확 84%, ±1클래스 100%. → **국물 농도/우러남을 연속값으로 추정**하는 직접 템플릿. ⚠️ 수중 물 투명도 검증(국물 아님).

### (c) 건더기 무름/연화 ✅ [high] — 우리 3단계 분류의 직접 템플릿
- **OnionBot (Imperial College 2020)**: 조리를 **레시피별 milestone 탐지**로 프레이밍, **'양파 넣음' vs '양파 무를 때까지 익음'을 whole-frame 분류기로 구별**(색 피처 안 씀). 무름 인식을 "가장 어려운 비전 태스크"로 명시.
- **레시피당 자가촬영 2,045장(4단계)~4,042장(6단계)**로 개별 모델 학습, 느린 단계는 undersampling으로 클래스 균형. → **국/탕별 3단계(미완/완료/과조리) whole-frame 분류기 + 소량 데이터** 설계에 그대로 적용.

## §2. 2뷰(Top + Oblique) 융합 (앵글 2) ✅ [high]
- **탑 + 정면(oblique) 2뷰 decision-level(late) 융합이 단일뷰보다 우수**: 젖소 연구에서 뷰별 YOLOv8 각각 → 규칙기반 앙상블로 뷰 충돌 조정 → F1 0.435(정면)/0.133(탑) → **0.481(2뷰)**.
- 다시점 인식 서베이(2024): 성능 좌우 설계축 = **카메라 배치 · 뷰 개수 · 뷰선택 전략 · 백본 · 융합전략**.
- ⚠️ 절대 F1 낮고 향상폭 작음(+0.046), 도메인은 축산. **주의: "탑뷰가 약하다"는 도메인 특수** — 솥은 수위·거품·증기를 탑에서 더 잘 봄. → **권고: oblique = 주(건더기 무름·국물 탁도), 탑 = 보조(수위·거품·증기·넘침).** 뷰가 서로 다른 물리신호를 볼 땐 late fusion 유리(단, early vs late는 실측 비교 필요 = 미해결).

---

## §3. 온도 시계열 + 비전 융합 (앵글 3) ✅ [high]
- **AquaFusionNet (2025-12)**: 비전 branch + 스칼라센서 시계열 branch를 **gated cross-attention**으로 융합. 학습되는 시그모이드 게이트 `g=σ(Wg[fv;ft])`, `f_fused = g⊙a + (1−g)⊙fv` → **모델이 온도센서 vs 시각 신뢰도를 스스로 조절.** MLX90614/90640 + RGB에 직접 이식 가능한 패턴.
- **어류 가공라인 레시피**: 느린 스칼라센서(1/min)를 버퍼링하며 30fps 프레임과 함께 **1Hz로 융합, 마지막 값 유지(hold-last)**. → **느린 단일점 센서(MLX90614) + 빠른 영상**을 맞추는 구체적 캐던스.
- ⚠️ 둘 다 수질/식품안전 도메인, 온도가 주신호가 아닌 여러 채널 중 하나 → 아키텍처로는 검증됐지만 "온도 지배" 시스템은 아님.

---

## §4. 소량 데이터 전략 (앵글 4) ✅ [high]
- **전이학습(1순위)**: 사전학습 **MobileNetV2**로 Food11에서 **1 epoch만에 ~9%→~80%**. 경량 백본 = 소량+엣지의 주 레버.
- **자기지도(SSL) 보조손실**: jigsaw/rotation 보조손실을 few-shot에 추가 → **상대오차 4~27% 감소, 데이터 적을수록·태스크 어려울수록 이득 큼**(ECCV 2020). *단, SSL과 본 태스크 이미지 분포가 다르면 역효과 → 타겟 데이터셋 내부 unlabeled로만.*
- **ProtoTransfer (2020)**: 2단계 자기지도 few-shot(증강 클러스터링으로 임베딩 학습 → 프로토타입 미세조정). 도메인 시프트에서 라벨 수십~수백배 적게 쓰고 지도학습급.
- **약지도(weak supervision)**: 온도·시간 휴리스틱을 **라벨링 함수로 프로그래밍 → 대량 자동라벨**. 웨어러블 시계열에서 **수작업 대비 AUROC 9% 이내**. → **온도임계값/시간으로 미완/완료/과조리 자동라벨** 근거. (Snorkel/Snuba 계열)

## §반박된 주장 (검증 탈락 — 오해 방지용으로 기록)
1. ❌ **BubbleID 세부 속성 주장**(개별 거품 위치·속도·계면형상·이탈까지 다 추출) — 0-3 반박. → 골격(분할+추적)은 유효, 세부 능력 과장.
2. ❌ **"doneness 직접 분류는 일반화 나빠서 ~50%밖에 안 됨"** — 1-2 반박. → **doneness 분류가 필연적으로 실패한다는 근거는 없음**(오히려 우리 접근에 유리한 정정).
3. ❌ **Jetson Xavier에서 RGB+thermal 융합 25.7 FPS, 정확도 손실 <2%** — 반박. → **검증된 엣지 지연/실시간 수치 없음.**
4. ❌ LSTM 온도+가스 부패예측 오차 10~15%↓ — 0-3 반박.
5. ❌ **MobileNetV3-Small + 프루닝 + INT8 = Jetson Nano 41FPS/8.7MB/4.8W** 구체 레시피 — 0-3 반박. → **검증된 경량 엣지 레시피 없음.**

→ **결론: 엣지 실시간 가능성은 "구조적으로 그럴듯"하지만 이 조사로 실증된 수치는 없음.** 실제 Jetson Orin Nano 벤치는 우리가 직접 재야 함.

## §이 과제에 대한 권고 (종합)

**모델 스택 (국/탕 특화)**
- **기본 = OnionBot식 whole-frame 3단계 분류기**(레시피=메뉴별), 백본은 **MobileNet/EfficientNet-lite**(전이학습). 데이터 2~4천장/메뉴 목표.
- **색-외 보조 신호 채널 추가**: 탑뷰에서 거품/끓음(YOLO 이산클래스) + 국물 탁도(YOLOv8-cls→회귀). oblique에서 건더기 무름.
- **온도 융합**: MLX90614 시계열을 **gated cross-attention**(AquaFusionNet식) 또는 최소한 aux input으로. 1Hz hold-last 캐던스.
- **2뷰**: oblique 주 + 탑 보조, **late(decision) fusion**으로 시작.
- **라벨**: 온도·시간 **약지도 자동라벨** + 과조리 경계는 소량 관능 앵커. SSL 보조손실로 라벨효율↑.
- **엣지 수치는 직접 벤치** (조사로는 미실증).
