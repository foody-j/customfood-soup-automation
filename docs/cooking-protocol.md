# 조리 데이터 수집 프로토콜 — 소고기무국 (초안 v0.1, 2026-10-02)

데이터셋 세션은 모두 이 절차를 따른다. 첫 세션 후 검토해 판을 올리고(v0.2 …) 바뀐 점을 아래 "변경 이력"에 남긴다.
근거: `docs/gt-definition-design.md`(3단계 정의·과조리까지 촬영), `docs/roadmap-2026-11.md`.

## 1. 역할 (최소 2명 권장)

- **조작 담당:** 인덕션·재료·뚜껑·맛보기.
- **기록 담당:** Pi 화면에서 사건 버튼을 누른다. 사건은 **일어난 즉시** 누르고, 늦게 누르면 발생 시각을 입력한다(사후 입력).
  혼자 할 때는 조작 직후 바로 누르고, 놓친 것은 세션 중 사후 입력으로 채운다.

## 2. 고정 조건 (세션마다 같게)

- 솥: 약 24 cm(같은 솥). 위치: 인덕션 중앙 표시. 카메라·열화상 위치·높이: 1단계에서 정한 고정값(사진 기록).
- 조명: 실내등 고정, 창 차단 여부 기록. PT100 탐침: 고정 지그, 감지부가 국물에 충분히 잠기는 깊이(1단계에서 확정).
- 재료: 비비고 소고기무국 2봉(같은 제품). 추가 물은 조건표대로.

## 3. 바꾸는 조건 (조건표에서 순환)

| 변수 | 수준 |
|---|---|
| 인덕션 출력 | 낮음 / 중간 / 높음 (단계 숫자 기록) |
| 추가 물 | 0 mL / 200 mL |
| 뚜껑 | 덮음 / 엶 |

12조합을 순서대로 돌고 남는 세션은 반복한다. 각 세션의 조건은 Pi 실험 설정 칸에 정확히 적는다.

## 4. 세션 절차

1. **점검 60초** 프리셋 실행 → 시작 전 점검 모두 정상 확인.
2. 데이터셋 프리셋 적용 → 조건 칸 채움(출력·물·뚜껑·시작 국물 온도·탐침 깊이·실측 중량).
3. 촬영 시작 → **재료 투입** 사건 → 가열 시작(**가열 변경** 사건, 출력 숫자 적기).
4. **끓음 시작** 사건(첫 기포), 이어 지속 끓음.
5. **맛보기**: 끓음 시작 뒤 2분마다(완료 근처에선 1분마다) 한 숟가락. 판정을 미완 / 완료 / 과조리 중 하나로 누른다.
6. **완료 시작**: 처음 "지금 먹기 좋다"고 판단한 시각. **완료 끝**: 더 두면 품질이 떨어지기 시작한다고 판단한 시각.
7. **과조리까지 계속** — 완료 끝 이후에도 최소 10분 또는 국물이 눈에 띄게 졸 때까지 촬영. **과조리** 사건을 누른다.
   (과조리 구간이 없으면 3단계 학습이 불가능하다.)
8. 가열 종료 사건 → 1분 더 촬영 → 중지. 종료 전 화면 경고(정답 사건 누락)를 확인한다.
9. 사진: 끝난 국 상태 1장(선택). 특이사항은 메모 사건으로.

## 5. 임시 판정 기준 (지도교수 확인 전)

> D-041(2026-10-05): 완료 정답의 기준점은 **표준 레시피(레토르트는 포장지 조리법)** 이고 PT100 온도 곡선으로 판정한다.
> 아래 맛보기 판정은 정답이 아니라 **검증용**으로 계속 기록한다(상세 `notes/fedora/labeling-standard-recipe.md`).

- **미완:** 무가 단단하거나 국물이 미지근·밍밍함.
- **완료:** 국물이 충분히 뜨겁고(끓음 지속) 무가 부드러움, 간이 맞음.
- **과조리:** 국물이 눈에 띄게 졸아 짜짐, 고기가 질겨짐, 무가 뭉개짐.
- 판정자는 세션마다 같은 사람을 우선한다. 판정자 이름(이니셜)을 조건 칸에 적는다.
