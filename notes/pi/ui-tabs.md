# pi/ui-tabs — 관리 화면을 탭으로 나눔 (2026-09-28)

- **요청:** 페이지가 너무 길어 실험 중 무엇을 눌러야 할지 찾기 힘듦 — 실험 칸을 나눠도 됨.
- **변경(`pi-server/app/static/` 전용):**
  - 탭 3개 — **실험**(촬영·사건 기록 → 열화상·PT100 → 카메라), **장치·설정**(Jetson 상태·저장소·Pi 상태·실험 설정·전원·모의 조작),
    **이력**(실험 이력·이벤트). 고른 탭은 브라우저에 기억(localStorage, 실패해도 기본 '실험').
  - 머리글에 작은 Jetson 상태 칩(어느 탭에서나 보임, 누르면 장치·설정 탭).
  - 촬영이 진행 중이면 시작 입력(프리셋·이름·재료·조건·최대 시간·미리보기·시작 전 점검)과 시작 버튼을 숨김 —
    진행 중 화면에는 세션 정보·중지 버튼·사건 기록·센서 화면만 남는다.
  - 이력 표는 좁은 화면에서 표 안에서만 가로 스크롤(390 px에서 페이지가 134 px 넘치던 문제 해결).
- **동작 불변:** API·서버 코드·저장 형식 변경 없음. 숨긴 탭의 미리보기 컴포넌트는 기존 IntersectionObserver 규칙으로 요청을 멈춘다.
- **검증:** 모의 서버(8125)+헤드리스 Firefox 1280×900·390×844 — 탭 전환·새로 고침 후 탭 유지, 장치 탭에서 미리보기 요청 0건,
  실험 탭 3초 6건(2카드×1 Hz), 진행 중 실험 탭 길이 2110→1703 px(데스크톱), 가로 넘침 없음, 콘솔 오류 없음. pytest 52 통과.
- **적용:** main 머지 후 운영 폴더에서 pull만 하면 정적 파일이라 새로 고침으로 반영(서비스 재시작 불필요).
