# 2026-09-26 — MAX31865 + PT100 첫 판독 성공

## 조건
- 보드: Voltly VLT-THM024(보라색 Adafruit 호환 클론, 핀 VIN/GND/3V3/CLK/SDO/SDI/CS/RDY). 같은 모델 2개 중 교체품.
- 배선(J12): GND 25 / CLK 23 / SDO 21 / SDI 19 / **CS 24(하드웨어 CS0)**, RDY 비움.
  전원: **J12 17번 3.3 V → 보드 VIN**(3V3 핀은 비움 — 정상 사용법).
- PT100 3선(파랑·파랑·빨강): F+ 파랑1 / RTD+ 파랑2 / RTD− 빨강, **RTD−↔F− 점퍼** → 4선 모드.
- 소프트웨어: `tools/sensor_check.py pt100 --cs-pin CE0 --ref-ohms 430 --wires 4 --count 10`
  (브랜치 `pt100-hw-cs`, spidev 하드웨어 CS 드라이버).

## 결과
- 10/10 유효, **29.15~29.22 ℃**, 저항 111.34~111.37 Ω, 원시값 8485~8487(±1 LSB), 취득 80 ms, 1.1 Hz.
- 원시값 ≈ 8486 → 기준 저항 **430 Ω(PT100용)** 실장 확인. 교체 불필요.
- 로그: `notes/data/logs/20260926_pt100_first-read.json`

## 관찰(무응답 → 성공까지)
| 단계 | 결과 |
|---|---|
| CS 16(GPIO), VIN 3.3 V | 전 레지스터 `0x00`(점퍼선 교체 전) / `0xFF`(교체 후) |
| SDO↔SDI 맞바꿈 | `0xFF` 동일 — 표기 반대 가설 기각 |
| 같은 모델 새 모듈 | 동일 — 개별 불량 가능성 낮음 |
| SCK 23↔15 점퍼 검사 | 20 kHz 전송 중 49,804회 변화 — SCK 정상 |
| VIN 3.3 V일 때 보드 3V3 핀 | **0 V** 측정 |
| 3.3 V를 3V3 핀에 직접 | `0x00` |
| **CS 24(하드웨어 CS0)** | **config `0xD1` 되읽기 성공(모드 1/3)** |
| CS를 16으로 되돌림 | 다시 `0x00` — CS 핀이 결정적 |
| PT100 3선(F− 비움) | 원시값 `32767`, 상한 fault — 보드 2/3선 점퍼 미설정(4선) |
| RTD−↔F− 점퍼 추가, `wires=4` | **정상 판독** |

VIN만으로 동작하므로 VIN 인가 중 3V3 핀 0 V 측정은 무응답의 원인이 아니었다(측정 조건 불명 — 재확인 안 함).

## 남은 일
- 보드 2/3선 납땜 점퍼 설정 → F− 점퍼 제거, `wires=3`.
- GPIO CS가 동작하지 않은 원인(미규명).
- 끓는 물·얼음물 2점 확인(GT 기준 온도로 쓰기 전).
