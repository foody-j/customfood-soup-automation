# Fedora 작업 지시서

Fedora(개발·통합 서버)가 Pi·Jetson 담당에게 넘기는 작업 지시서를 둔다. 파일명 `YYYYMMDD-<작업명>-<pi|jetson>.md`.

- 지시서는 **그 장비의 Claude에게 그대로 붙여 넣을 수 있게** 쓴다: 목표, 근거(D 번호·노트), 수정할 파일, 하지 말 것, 완료 조건, 보고 형식.
- 장비 담당은 최신 main에서 `python3 tools/dev_session.py start <역할> <작업명>`으로 시작해 지시서를 수행하고,
  결과는 `notes/<역할>/<작업명>.md`에 기록한 뒤 브랜치를 push한다. Fedora가 검토·통합한다.
- 지시서는 요청이지 경로 권한을 넓히지 않는다. 지시서와 실물·코드가 다르면 장비 담당이 판단하고 노트에 이유를 남긴다.
- 운영 서비스 적용(재시작)은 지시서에 적어도 장비 담당이 진행 중 세션이 없을 때 직접 한다.
