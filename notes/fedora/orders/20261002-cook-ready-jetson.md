# 작업 지시서 — Jetson: 첫 조리 준비 (저장량·PT100·카메라·시계) (2026-10-02)

**시작:** `drop-gemini` 지시서(`20261001-drop-gemini-jetson.md`)를 먼저 끝낸 뒤
`python3 tools/dev_session.py start jetson cook-ready` → 이 파일을 읽고 수행.
**근거:** `docs/roadmap-2026-11.md` 1단계, `docs/cooking-protocol.md`, `notes/jetson/boil-rehearsal.md`(PT100 93 ℃).
**배경:** 11월 말까지 소고기무국 25~30세션(각 40~60분, 과조리까지)을 모은다. 원본은 Fedora로 옮겨 보관한다.

## 목표
첫 데이터셋 세션 전에 저장 용량·센서 값·카메라 상태·시계를 확인해 수치로 남긴다. 코드 변경은 필요할 때만.

## 할 일
1. **저장량 실측(Gemini 제외 4센서)** — 가열 없이 5분 세션을 fps 10과 fps 2로 각각 촬영.
   스트림별 바이트/분(manifest 기준), 60분 세션 예상 용량, 현재 디스크 여유로 몇 세션 보관 가능한지 표로 기록.
   JPEG 품질 설정값도 함께 기록. (fps 결정은 이 표를 보고 Fedora·사용자가 한다)
2. **PT100 재측정** — 탐침 감지부가 충분히 잠기게 고정(깊이 mm 기록) → 끓는 물 3분 유지 값.
   여전히 ~100 ℃와 3 ℃ 이상 차이면 얼음물(0 ℃) 값도 측정해 2점 보정 계수 후보를 노트에 기록.
   **수집 원본·장치 설정은 고치지 않는다**(보정은 Fedora 데이터셋 단계).
3. **카메라** — GMSL2 ① 흐림 원인(렌즈 오염·초점·김서림) 확인·조치. 두 카메라·열화상의 고정 위치·높이·각도를 사진과 수치로 기록.
   끓는 물 5분 동안 김서림 정도 관찰(미리보기 캡처 몇 장, 작은 파일만 노트 하위에).
4. **시계 동기** — Jetson NTP 동기 상태(`timedatectl`), 서버, Pi와의 오차(예: Pi와 Jetson에서 동시에 `date +%s.%N` 비교 또는 chrony).
   오차가 0.5초를 넘으면 원인과 동기 방법(Pi를 NTP 서버로 쓰는 등)을 제안. 설정 변경은 사용자 확인 후.
5. **Fedora 반출 준비** — 세션 디렉터리 경로·권한 확인, `manifest.json`의 `checksum_state`가 `done`이 되기까지 걸리는 시간(10분 세션 기준) 기록.
   **반출은 Fedora가 매일 밤 01:00 네트워크로 자동으로 한다(10/03 결정, SSD는 예비).** Jetson 쪽 할 일은 없다 — 원본은 Fedora 검증 OK
   통보 뒤에만 지운다. 예비용으로 SSD 복사 절차(마운트 경로, `rsync -a`)만 노트에 짧게 적는다.

## 하지 말 것
- Pi 코드 수정 금지. 계약 변경 없음. 운영 서비스 자동 재시작 금지.
- 기존 세션 원본 삭제 금지(Fedora 검증 완료 통보 뒤 수동 정리 — 이번 작업 범위 아님).
