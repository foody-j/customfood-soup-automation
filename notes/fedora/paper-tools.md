## 변경
- `docs/analysis-plan.md` v1.0(**데이터 수집 전 동결**): RQ1~4, H1(탐침 없는 모델 vs 시간·조건 기준선, 세션별 Wilcoxon 단측), 실험 설계
  (물 → 기준 반복 → 조건 변화, 블록 무작위화), 라벨(D-041), **제외 기준 E1~E6**, 주 지표(완료 알림 절대오차 중앙값), CI·검정·Holm,
  민감도 S1~S6, 계획된 표·그림. 변경은 문서 끝 기록에 남긴다.
- `soupdata/design.py` + `schedule`: 블록 무작위화(고정 시드) + 기준 조건 반복 고르게 끼우기 + 물 가열 순서. 프로토콜 v0.2에 반영.
- `soupdata/provenance.py`: 출처 도장 — 데이터셋 summary, `baseline` metrics·report, 논문 묶음에 기록.
- `soupdata/stats.py`: 세션 부트스트랩 CI, 짝지은 Wilcoxon·Holm, Bland–Altman, 가중 κ, 1차 가열 모델, 반복 CV, 조건 효과(KW·Spearman·OLS 유형 II).
- `soupdata/paper.py` + `paper`: 표 T1~T5(CSV·MD·LaTeX), 그림 F2~F10(PNG 300 dpi·PDF, 영/한). F1(시스템·센서 배치)은 사람이 준비.
  dataviz 지침: 축 하나·고정 범주 색(기준선 회색)·순서형 파랑·범례/직접 라벨·그림을 직접 열어 겹침 확인(범례 위치·정렬 수정).
- `tools/make_bib.py` → `docs/references.bib` **40항목**(Crossref DOI·arXiv API·제목 검색 0.9 이상만, 법령 3건 수동). 문헌 R4 저자 확인.

## 검증
- 테스트 45개 통과(새: 순서표·출처·통계 5·논문 생성 2). 통계는 정답을 아는 값으로(편향 2.0·τ 900초 복원, Holm 단조성 등).
- 합성 데이터셋 논문 묶음 직접 확인: 세션 5개 단측 Wilcoxon 최소 p = 1/32 = 0.031(이론값과 일치), 그림 9개 겹침 없음.
- **실제 조리 데이터 없음** — 모든 결과 숫자는 합성 검증용이다.
